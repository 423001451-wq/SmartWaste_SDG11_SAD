# Smart Waste Collection and Monitoring System

## 🌱 SDG Alignment
This project supports **SDG 11 – Sustainable Cities and Communities** by improving waste management efficiency through a digital monitoring and scheduling system.

---

## 📌 Project Overview
The **Smart Waste Collection and Monitoring System** is a web-based application designed to modernize barangay waste management operations. It helps coordinate waste collection schedules, manage complaints, monitor collection status, and generate reports for administrators.

The system improves communication between residents, waste collection staff, and administrators, ensuring cleaner and more sustainable communities.

---

## 🎯 Objectives
- Automate waste collection scheduling
- Improve complaint handling and tracking
- Provide real-time monitoring of waste collection activities
- Generate automated reports and analytics
- Enhance communication between stakeholders

---

## 👥 User Roles

### 1. Administrator
- Manage users
- Create and assign schedules
- Monitor system performance
- Generate reports
- Handle complaints

### 2. Waste Collection Staff
- View assigned schedules
- Update collection status
- Submit operational reports
- Respond to complaints

### 3. Residents
- View collection schedules
- Submit complaints
- Receive notifications
- Track complaint status

---

## 🏗️ System Architecture
The system follows a **3-Tier Architecture**:

- **Presentation Layer:** HTML, CSS, Bootstrap, JavaScript  
- **Logic Layer:** PHP (business logic and processing)  
- **Data Layer:** MySQL database
